# Murder Mystery 2 Delta Executor Scripts

This project contains a collection of scripts designed to enhance the gameplay of Murder Mystery 2 on Roblox. The scripts include features such as candy collection, knife inventory management, and a delta executor to streamline gameplay. These scripts are intended for use in Roblox games and are compatible with the Murder Mystery 2 game environment.

## Install

1. Open Roblox Studio.
2. Create a new script in the ServerScriptService or a suitable location in your game hierarchy.
3. Copy and paste the contents of each script into the respective script files in your game.
4. Adjust the configuration settings in the Config.lua file as needed.

## Use

1. Ensure all scripts are properly linked and configured.
2. Test the scripts in a private server to ensure they work as expected.
3. Monitor the game for any issues and make adjustments as necessary.
